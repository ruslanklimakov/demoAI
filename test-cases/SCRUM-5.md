# Test Cases — SCRUM-5: Radio Button
**URL:** https://demoqa.com/radio-button  
**Date:** 2026-05-03  
**Coverage:** 10 scenarios (3×P0, 4×P1, 3×P2)

---

Feature: Radio Button на странице demoqa.com/radio-button

  Background:
    Given пользователь открыл страницу https://demoqa.com/radio-button

  # ────────────────────────────────────────────────────────────────
  # P0 — Критические (блокируют релиз)
  # ────────────────────────────────────────────────────────────────

  @P0
  Scenario: [P0] Начальное состояние — ни одна кнопка не выбрана
    Then радио-кнопка "Yes" не выбрана
    And радио-кнопка "Impressive" не выбрана
    And подтверждающий текст отсутствует на странице

  @P0
  Scenario: [P0] Выбор "Yes" — кнопка выбрана, отображается корректный текст
    When пользователь кликает на радио-кнопку "Yes"
    Then радио-кнопка "Yes" становится выбранной
    And на странице отображается текст "You have selected Yes"

  @P0
  Scenario: [P0] Выбор "Impressive" — кнопка выбрана, отображается корректный текст
    When пользователь кликает на радио-кнопку "Impressive"
    Then радио-кнопка "Impressive" становится выбранной
    And на странице отображается текст "You have selected Impressive"

  # ────────────────────────────────────────────────────────────────
  # P1 — Важные (должны быть покрыты до релиза)
  # ────────────────────────────────────────────────────────────────

  @P1
  Scenario: [P1] Взаимоисключаемость — при выборе "Impressive" кнопка "Yes" снимается
    When пользователь кликает на радио-кнопку "Yes"
    And пользователь кликает на радио-кнопку "Impressive"
    Then радио-кнопка "Impressive" становится выбранной
    And радио-кнопка "Yes" не выбрана
    And на странице отображается текст "You have selected Impressive"

  @P1
  Scenario: [P1] Взаимоисключаемость — при выборе "Yes" после "Impressive" кнопка "Impressive" снимается
    When пользователь кликает на радио-кнопку "Impressive"
    And пользователь кликает на радио-кнопку "Yes"
    Then радио-кнопка "Yes" становится выбранной
    And радио-кнопка "Impressive" не выбрана
    And на странице отображается текст "You have selected Yes"

  @P1 @bug
  Scenario: [P1] БАГ: Кнопка "No" отображается, но заблокирована (disabled)
    Then радио-кнопка "No" присутствует на странице
    And радио-кнопка "No" имеет атрибут disabled
    And радио-кнопка "No" не доступна для клика

  @P1
  Scenario: [P1] Подтверждающий текст обновляется при смене выбора
    When пользователь кликает на радио-кнопку "Yes"
    Then на странице отображается текст "You have selected Yes"
    When пользователь кликает на радио-кнопку "Impressive"
    Then на странице отображается текст "You have selected Impressive"
    And текст "You have selected Yes" больше не отображается

  # ────────────────────────────────────────────────────────────────
  # P2 — Желательные (покрыть при наличии ресурсов)
  # ────────────────────────────────────────────────────────────────

  @P2
  Scenario: [P2] Выбранная кнопка остаётся выбранной при повторном клике
    When пользователь кликает на радио-кнопку "Yes"
    And пользователь кликает на радио-кнопку "Yes" повторно
    Then радио-кнопка "Yes" остаётся выбранной
    And на странице отображается текст "You have selected Yes"

  @P2
  Scenario: [P2] Страница содержит заголовок "Radio Button"
    Then на странице присутствует заголовок "Radio Button"

  @P2
  Scenario Outline: [P2] Доступность — радио-кнопки определяются по роли и имени
    Then элемент с ролью "radio" и именем "<label>" присутствует в дереве доступности

    Examples:
      | label      |
      | Yes        |
      | Impressive |
      | No         |
